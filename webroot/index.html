About NoBricking

🛡️

NoBricking

Version 1.0.4

Anti-Bricking Protection

NoBricking is an advanced module that automatically protects your device from bricking by monitoring boot attempts and restoring backups when failures are detected.

Key Features

  • ✅ Automatic partition backup (boot, init_boot, recovery)
  • ✅ Boot failure detection with flag system
  • ✅ Automatic restoration after 3 failed boots
  • ✅ Module state management
  • ✅ Manual backup creation
  • ✅ Customizable restore settings
  • ✅ Advanced web interface

Compatibility

  • Magisk (all versions)
  • KernelSU (original)
  • KernelSU Next
  • Sukisu Ultra
  • APatch
